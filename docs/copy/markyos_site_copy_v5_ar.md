### 0.2 Seven rules for every page

| # | Rule |
| :-: | :--- |
| 1 | **Say what it is first.** A cold visitor must know Markyos is a bilingual brand hub within three seconds. A slogan never stands alone above the fold |
| 2 | **One idea per section.** One headline, one sentence, one visual, one action |
| 3 | **Short by default.** Headline 8 words at most. Sub one or two sentences. Lists 5 items at most. Pricing and the comparison table are the exceptions |
| 4 | **Show, then say.** The visual carries the feature. The copy carries the benefit |
| 5 | **One message, written natively twice.** Arabic and English make the same promises, carry the same sections and the same questions. Only the wording is native to each |
| 6 | **Tell each story once.** The problem section shows the stops; the comparison table carries the detail. Nothing is said twice on one page |
| 7 | **No proof we don't have.** No invented logos, quotes or numbers, no "most popular" before launch. The proof slot stays empty until the beta gives real names, with permission |

### 0.3 The style

| # | Tool | Tag |
| :-: | :--- | :--- |
| 1 | Short line, full stop as rhythm | *Tool: rhythm* |
| 2 | Rule of three | *Tool: three* |
| 3 | Internal rhyme (AR) · alliteration or sound (EN) | *Tool: rhyme* |
| 4 | Structural repetition | *Tool: repetition* |
| 5 | Antithesis | *Tool: antithesis* |
| 6 | Double meaning | *Tool: double meaning* |
| 7 | Benefit before feature | *Tool: benefit first* |

**Limits:** one rhymed line per section at most, usually the headline · no superlatives · none of: seamless, revolutionary, unlock, leverage, game-changer, cutting-edge, empower, effortless, ثوري، سلس · no exclamation marks · no emojis · no dashes in the copy · Arabic is written first, not translated · no calques («اظهر بحجم فريق»، لا «اظهر كفريق كامل») · every feature named matches Notion's status.

### 0.5 How this file is written

- **Copy blocks:** the Arabic line, then the English line, in one block.
- **Tables:** an `AR` column and an `EN` column; labels written «عربي · English».
- **Rows marked (AR) or (EN)** belong to one language only.
- **URLs** are the Arabic site's. The English site uses the same paths under `/en/`.
- **Plan names:** المجانية · مستقل · استوديو · شركة / Free · Freelancer · Studio · Company. The old names (Pro, Brand, Team, Agency, Business, Project Pass) are not used anywhere.
- **Chips:** «[شارة: قريباً]» / `[CHIP: Coming soon]` for anything not live at launch, with no dates. No chip means live at launch, 15 February 2027.
- **Buttons and links:** «[زر: …]» / `[Button: …]`, «[رابط: …]» / `[Link: …]`.
- **Brand Brain is the engine.** It's in the top navigation, fourth on the homepage, and every feature page where it works has a «عقل العلامة هنا» / "Brand Brain here" line; every audience page has «عقل العلامة معك» / "Brand Brain with you".

## 3. The Interactive Hero: Spec

Stack: Next.js, Tailwind tokens from `framer-DESIGN.md`, Framer Motion. The hero is the first frame of the product story in section 2.4.

### 3.1 Layout

| Element | Spec |
| :--- | :--- |
| Canvas | The design system's near-black |
| Eyebrow | Small, muted, centred above the H1, one line on mobile |
| H1 | Two lines, each an inline-block span with a hard break, animated separately |
| H1, Latin | Display face, weight 500, about 62px, tracking about −0.025em, line height about 1.16 |
| H1, Arabic | Arabic display face, same size or one step larger, **no negative tracking**, line height about 1.3 |
| Sub | About 0.45× the headline, one line on desktop |
| Buttons | Two pills, equal size, the single accent blue |
| Stage | One relative container, about 1080px wide, holding the app window and both cards |
| App window | Translucent dark surface, radius about 27px, hairline edge, peeking up from the bottom. Shows the demo brand's hub in the page language |
| Cards and tags | Rounded, strong shadow; warm name tags under each |

### 3.2 Coordinates and motion

- Both cards sit in the **same container as the window**, anchored to its centre (`left: 50%; top: 50%`) plus an offset, so dropping a card in is a tween of `x` and `y` to 0. Arabic: card 1 on the right. English: card 1 on the left.
- **Entrance:** announcement bar → nav → eyebrow → H1 line 1 → line 2 → sub and buttons → cards (from blurred and dim) → tags → window slides up. Each element `initial={{ opacity: 0, y: 20, filter: 'blur(8px)' }}`, staggered.
- **Section 2.4** pins the window and swaps it through three stages: Create (form, report, card 1 drops in, guide builds), Deliver (ownership chip moves), Run (card 2 drops in, tone score).

### 3.3 Rules

- **Real product only.** Every screen is recorded from or rendered by the real app.
- **Name tags are never live cursors.** Markyos has no real-time co-editing; the tags only label who did what.
- **No moodboard** in the story until moodboards ship.
- **Reduced motion:** stills, chapters as tabs.
- **Below 810px:** cards above the window; chapters become swipeable tabs.
- **Performance:** loops under 8 seconds, lazy-loaded after the first frame.
